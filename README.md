# Portal de Notícias

Landing page desenvolvida durante a trilha de Fullstack da Rocketseat, simulando a página inicial de um portal de notícias de tecnologia (estilo TechCrunch/The Verge).

## 🔍 Sobre o projeto

O objetivo é praticar HTML semântico e CSS puro na construção de uma página de notícias, trabalhando com:

- Estruturação semântica (`header`, `nav`, `main`, `section`, `article`, `aside`)
- Estilização com variáveis CSS (`:root`)
- Flexbox e Grid para layout (destaques, mais lidas, viu isso aqui)
- Tipografia customizada com Google Fonts (Archivo)
- Aninhamento de seletores em CSS puro

## 🚀 Tecnologias

- HTML5
- CSS3

## 📁 Estrutura do projeto

```
portal-de-noticias/
├── assets/
│   ├── icons/       # Ícones utilizados na página
│   └── image/       # Imagens das matérias e anúncios
├── style/
│   ├── global.css   # Variáveis globais e reset
│   └── style.css     # Estilos da página
└── index.html        # Estrutura principal da página
```

## ▶️ Como executar

Basta abrir o arquivo `index.html` em um navegador de sua preferência.
